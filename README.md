# nhanes-data-cleaning-r
An introductory R project using NHANES 2017–2018 data in Posit Cloud. I practiced importing and merging datasets, filtering adults, selecting variables, and removing missing values. The cleaned dataset includes 5,434 adults with height, weight, gender, and race/ethnicity data, helping me build foundational R skills.

I found the data that is given in the Posit Cloud file, from UC Berkeley’s Health Statistics and Data source. I input them with R in Posit Cloud with the reference to the CDC’s NHANES 2017-18 demographics and body measurements files. 


The following sources used for this:

UC Berkeley:
https://guides.lib.berkeley.edu/publichealth/healthstatistics/rawdata

Demographics: 
https://wwwn.cdc.gov/nchs/data/nhanes/public/2017/datafiles/DEMO_J.htm

Body Measurements:
https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/BMX_J.htm
